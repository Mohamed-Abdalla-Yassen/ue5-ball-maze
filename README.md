# UE5 Ball Maze

A simple physics-based ball-and-maze game built in Unreal Engine 5. Navigate a rolling ball through a maze using keyboard controls, with jump mechanics and a custom material applied to the ball.

This is my **first project in Unreal Engine 5**, built while learning the basics of Blueprints, physics simulation, and input handling.

## Features
- Physics-driven ball movement (roll and jump)
- Custom-textured ball
- Single-level maze navigation
- Keyboard controls (WASD/Arrow keys + Space to jump)
